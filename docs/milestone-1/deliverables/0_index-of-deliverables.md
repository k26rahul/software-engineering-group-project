# Milestone 1 Deliverables

This document lists all deliverables for Milestone 1: Project Initiation & Requirements Gathering. Each deliverable is maintained as a separate file present alongside this document - please check out the individual files for the actual contents.

---

## ✅ Problem Statement

### 1_Problem Statement.pdf

Describes the current paper-based operations of the RVK campus library, the administrative overload they cause, and how a digital Library Management System will transform workflows for both the librarian and members.

---

## ✅ Identification of Users

### 2_Users of Application.pdf

Defines detailed personas for the librarian, library members, campus management, and tertiary stakeholders - outlining each user's role, access level, and specific interactions with the system.

---

## ✅ User Research and Requirements Gathering

### 3.1_Requirements Gathering.pdf

Outlines the four research methods used - informal conversations, naturalistic observation, formal interviews, and secondary research - along with the key insights each method produced.

### 3.2_Interview Questions and Responses.pdf

Contains the structured interview questions prepared for the librarian and library members, along with summarized responses documenting their current workflows, frustrations, and unmet needs.

### 3.3_Pain Points and Concerns.pdf

Maps out every current manual workflow in the library - from issuing books and tracking returns to managing subscriptions and budgets - and identifies the specific bottlenecks and failure points in each.

---

## ✅ User Stories and Requirements Analysis

### 4_User Stories.pdf

A comprehensive set of SMART user stories organized by user persona (librarian, members, campus management), each mapping a specific pain point to a desired system capability.

### 5_Requirements Analysis.pdf

Maps identified pain points to concrete system modules and features, defining what each module solves and the specific functionality it will provide.
