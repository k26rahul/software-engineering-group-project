# Milestone 2 Deliverables

This document lists all deliverables for Milestone 2: Scheduling & Design. Each deliverable is maintained as a separate file present alongside this document - please check out the individual files for the actual contents.

---

## ✅ Design of Components

### 1_Design of Components.md

Explains the design process, three-tier system architecture (Frontend, Backend, Database), and how the 9 functional modules from Milestone 1 decompose into actual software components. Includes inter-component workflows and a module-to-component traceability matrix.

### 1.1_Frontend Components.md

Page components organized by user role (Common, Librarian, Member, Campus Management) and shared reusable UI components.

### 1.2_Backend Components.md

API routers with endpoint definitions, service classes with method signatures, cross-cutting concerns, and dependency mappings (service-to-service and service-to-model).

### 1.3_Database Components.md

Enumerations, data model classes with attributes, types, constraints, and methods, and model-to-model relationships with cardinality.

---

## ✅ Class Diagram

### 2_Class Diagram.md

Describes what the UML class diagram contains - data models, services, enumerations, and the four types of relationships used. The actual Mermaid diagram code will be generated from this specification.

---

## ✅ Database Design Diagram

### 3_Database Design Diagram.md

Describes what the ER diagram contains - database entities (mapped from data models), their attributes, and relationships with cardinality. The actual Mermaid diagram code will be generated from this specification.
