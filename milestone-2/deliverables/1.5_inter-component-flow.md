# Inter-Component Flow

## How Components Interact (Inter-Component Flow)

Here is how the components connect across the three tiers for key workflows:

### Workflow: Member Issues a Book

```mermaid
flowchart TD
    A["Member clicks 'Issue' on BorrowingDashboardPage"] --> B["Frontend: IssuePage"]
    B -- "HTTP POST" --> C["Backend: circulation_router<br>(/transactions/issue)"]
    C --> D["CirculationService"]
    D --> E["CatalogService<br>(check availability)"]
    D --> F["MemberService<br>(check fines)"]
    D --> G["ReservationService<br>(check reservation)"]
    E --> H["BookCopy<br>(model)"]
    F --> I["User / Fine<br>(models)"]
    G --> J["Reservation<br>(model)"]
    H --> K["Transaction (model)<br>← new record created"]
```

### Workflow: Book is Returned with Active Reservation

```mermaid
flowchart TD
    A["Librarian processes return on ReturnPage"] --> B["Frontend: ReturnPage"]
    B -- "HTTP POST" --> C["Backend: circulation_router<br>(/transactions/return)"]
    C --> D["CirculationService"]
    D --> E["FineCalculation<br>(if damaged/lost)"]
    D --> F["ReservationService<br>(check waitlist)"]
    E --> G["Fine<br>(model)"]
    F --> H["NotificationService"]
    H --> I["EmailClient<br>(notify queued member)"]
```
