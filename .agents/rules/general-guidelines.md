# Project Guidelines

## SE Project Structure
- `docs/se_project_structure.md` describes the **software engineering course project framework** - not the library management system itself.
- It covers: team roles, the 5-milestone roadmap with deliverables, branching/PR/code-review rules, and grading criteria.
- **Read this file only if** you need information about the project's milestone structure, submission requirements, team responsibilities, or workflow rules.

## Library Management System - Milestone Documents
- `milestone-1/deliverables/` contains requirements-gathering deliverables for the library management system (problem statement, user personas, user research, user stories, requirements analysis).
- **Read these files only if** you need specific domain knowledge about the LMS - e.g., what users exist, what pain points were identified, or what features are required.
- Start with `milestone-1/deliverables/0_index-of-deliverables.md` to see what each file covers, then read only the specific file(s) relevant to your task.

## Restrictions
- **DO NOT** read any PDF files anywhere in the project. Reading PDFs wastes tokens unnecessarily.
